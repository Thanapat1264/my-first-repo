# นิสัยประจำวัน

แอปติดตามนิสัยสำหรับมือถือ ติ๊กทุกวัน ดูสตรีค (วันที่ทำต่อเนื่อง) และสถิติ
เป็นเว็บแอป (PWA) ติดตั้งลงหน้าจอโฮมได้ ใช้ออฟไลน์ได้ ข้อมูลเก็บในเครื่องของคุณ ไม่มีเซิร์ฟเวอร์ ไม่ต้อง build

## ทำอะไรได้บ้าง

- **ติ๊กนิสัยรายวัน** แถบ 7 วันด้านบนใช้ย้อนไปติ๊กวันที่ลืมได้ ส่วนเดือนก่อนหน้าทำจากปฏิทินในหน้ารายละเอียดของแต่ละนิสัย
- **เป้าหมายแบบนับครั้ง** เช่น ดื่มน้ำ 8 แก้ว แตะ + ทีละแก้ว วงแหวนรอบปุ่มบอกความคืบหน้า
- **ไอคอน** เลือกจากชุดสำเร็จรูป หรือแตะช่องใต้ตารางแล้วใช้คีย์บอร์ดอีโมจิของเครื่อง (iPhone กดปุ่มรูปโลก) เลือกตัวไหนก็ได้ รวมถึงธง สีผิว และอีโมจิที่ประกอบหลายส่วน
- **กำหนดวันที่ทำ** ทุกวัน จันทร์–ศุกร์ หรือเลือกเอง วันที่ไม่อยู่ในตารางจะไม่ทำให้สตรีคขาด
- **สตรีค** ต่อเนื่องตอนนี้และสูงสุด วันนี้ที่ยังไม่ทำจะไม่ทำให้สตรีคขาดจนกว่าจะข้ามไปวันใหม่
- **วันหยุด** วันไหนไม่สะดวกทำ กด "ตั้งเป็นวันหยุด" ได้ทั้งวัน (เฉพาะนิสัยที่ยังไม่ได้เริ่ม) หรือเลือกรายนิสัยจากปฏิทินในหน้ารายละเอียด
  วันหยุดไม่ทำให้สตรีคขาด และไม่นับเป็นวันที่พลาดในอัตราสำเร็จ
- **พักนิสัย** ไปเที่ยวหรือป่วยหลายวัน กด "พัก" ในหน้ารายละเอียด นิสัยจะหายจากรายการของวันนั้น
  สตรีคและอัตราสำเร็จข้ามช่วงพักไปให้ กด "กลับมาทำต่อ" เมื่อพร้อม (ข้อมูลเดิมไม่หาย)
- **เหรียญสตรีค** ต่อเนื่องครบ 7 / 30 / 100 วัน ได้เหรียญพร้อมการ์ดฉลอง เหรียญที่ได้แล้วอยู่ในหน้ารายละเอียดและไม่หายแม้สตรีคขาดทีหลัง
  (ถ้าเปิดโหมด "ลดการเคลื่อนไหว" ในระบบไว้ จะเห็นเฉพาะการ์ด ไม่มีดอกไม้กระดาษ)
- **สถิติ** อัตราสำเร็จ 7 และ 30 วัน กราฟแท่งรายวัน แผนที่สี 12 สัปดาห์ และสรุปแต่ละนิสัย
- **เทียบกับสัปดาห์ก่อน** 7 วันล่าสุดเทียบกับ 7 วันก่อนหน้านั้น ทั้งภาพรวมและรายนิสัย เป็นการแสดงผลอย่างเดียว ไม่มีการบันทึกหรือแชร์
- **เตือนผ่านปฏิทินมือถือ** ตั้งเวลาเตือนต่อนิสัย แล้วส่งเข้าแอปปฏิทินของเครื่อง (ดูหัวข้อ "เตือนผ่านปฏิทิน" ด้านล่าง)
- **ธีมสว่าง / มืด / ตามระบบ** วันที่แสดงเป็นภาษาไทยและปี พ.ศ.
- **สำรองข้อมูล** ส่งออกและนำเข้าเป็นไฟล์ JSON

## เปิดบนมือถือ (GitHub Pages)

แอปนี้เป็นไฟล์ static ล้วน ๆ เปิดผ่าน GitHub Pages ได้เลยโดยไม่ต้องตั้งค่าอะไรเพิ่ม

1. ไปที่ **Settings → Pages** ของ repo นี้
2. ที่ **Build and deployment** เลือก **Source: Deploy from a branch**
3. เลือก Branch เป็น `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
   (ถ้ายังไม่ได้ merge ให้เลือกบรานช์ `claude/habit-tracking-app-cv6q51` แทนได้)
4. รอ 1–2 นาที แล้วเปิด <https://thanapat1264.github.io/my-first-repo/> บนมือถือ

### ติดตั้งลงหน้าจอโฮม

- **iPhone / iPad** เปิดด้วย Safari แตะปุ่มแชร์ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม"
- **Android** เปิดด้วย Chrome แตะเมนู ⋮ แล้วเลือก "ติดตั้งแอป"

ติดตั้งแล้วจะเปิดเต็มจอเหมือนแอปทั่วไปและใช้ได้แม้ไม่มีอินเทอร์เน็ต

> **สำคัญสำหรับ iPhone:** แอปที่ติดตั้งลงหน้าจอโฮมใช้ที่เก็บข้อมูลแยกจาก Safari
> ควรติดตั้งก่อนเริ่มบันทึก ถ้าใช้ใน Safari ไปแล้ว ให้ส่งออกข้อมูลจาก Safari
> แล้วนำเข้าในแอปที่ติดตั้ง (ตั้งค่า → สำรองข้อมูล)

## เตือนผ่านปฏิทิน

เว็บแอปที่ไม่มีเซิร์ฟเวอร์ส่งแจ้งเตือนตอนปิดแอปอยู่ไม่ได้ จึงใช้แอปปฏิทินของเครื่องเป็นตัวเตือนแทน

1. เปิดหน้าสร้างหรือแก้ไขนิสัย แล้วตั้ง **เตือนผ่านปฏิทินมือถือ** เป็นเวลา เช่น 07:30 จากนั้นกดบันทึก
2. เปิดหน้ารายละเอียดของนิสัยนั้นแล้วกด "เพิ่มลงปฏิทิน" หรือกด "เพิ่มเตือนทั้งหมดลงปฏิทิน" ที่ ตั้งค่า → เตือนผ่านปฏิทิน
3. เครื่องจะเปิดหน้าแชร์ (หรือดาวน์โหลดไฟล์ `.ics`) ให้เลือกแอปปฏิทิน แล้วกดยืนยันเพิ่มกิจกรรม

สิ่งที่ควรรู้

- กิจกรรมเป็นแบบ **ซ้ำตามวันที่กำหนดของนิสัย** (ทุกวัน หรือเฉพาะวันที่เลือก) เตือนตรงเวลา และใช้เวลาตามเครื่อง ไม่ผูกเขตเวลา
- ปฏิทินไม่รู้ว่าคุณติ๊กแล้วหรือยัง จึงเตือนทุกครั้งตามเวลาแม้ทำเสร็จแล้ว หรือแม้ตั้งวันหยุด/พักนิสัยไว้
- ไฟล์เป็นข้อมูล ณ ตอนที่กดเท่านั้น ถ้าเปลี่ยนเวลา เปลี่ยนวันที่ทำ หรือลบนิสัย ให้ลบกิจกรรมเก่าในปฏิทินแล้วเพิ่มใหม่
  (กิจกรรมของแต่ละนิสัยใช้รหัสเดิมทุกครั้ง แอปปฏิทินบางตัวอาจอัปเดตทับให้เอง แต่ไม่รับประกัน)
- ใช้ได้เฉพาะเว็บแอปนี้ (GitHub Pages) ส่วนหน้า artifact บน claude.ai ซ่อนส่วนนี้ไว้ เพราะดาวน์โหลดไฟล์ `.ics` ไม่ได้

## ข้อมูลของคุณ

- ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์บนเครื่องนั้น **ไม่ถูกส่งไปที่ใด และไม่ซิงก์ข้ามเครื่อง**
- ถ้าล้างข้อมูลเว็บไซต์ในเบราว์เซอร์ ข้อมูลจะหาย ให้ส่งออกไฟล์สำรองไว้เป็นระยะ
- Safari บน iPhone ล้างข้อมูลเว็บที่ไม่ได้เปิดเกิน 7 วัน ยกเว้นแอปที่ติดตั้งลงหน้าจอโฮม
- ย้ายเครื่อง: ส่งออกจากเครื่องเดิม แล้วนำเข้าในเครื่องใหม่

## พัฒนาต่อ

ไม่มีขั้นตอน build แก้ไฟล์แล้วรีเฟรชได้เลย

```bash
python3 -m http.server 8000   # หรือ npx serve .
# เปิด http://localhost:8000
npm test                      # ทดสอบตรรกะ (ต้องใช้ Node 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจ)
```

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | โครงหน้า |
| `css/styles.css` | สไตล์ทั้งหมด รวมสีธีมสว่าง/มืดและสี 8 สีของนิสัย |
| `js/logic.js` | ตรรกะล้วน: วันที่ สตรีค วันหยุด/พักนิสัย เหรียญ เทียบสัปดาห์ สร้างไฟล์ `.ics` การตรวจข้อมูลนำเข้า (ไม่แตะหน้าจอ จึงทดสอบง่าย) |
| `js/app.js` | หน้าจอ การเก็บข้อมูล และการโต้ตอบ |
| `sw.js` | service worker สำหรับใช้ออฟไลน์ |
| `manifest.webmanifest`, `icons/` | ข้อมูลสำหรับติดตั้งลงมือถือ |
| `tests/logic.test.js` | ชุดทดสอบของ `logic.js` |

รองรับเบราว์เซอร์รุ่นใหม่ (iOS 15.4 ขึ้นไป, Chrome/Edge/Firefox/Safari ตั้งแต่ปี 2022)

## ยังไม่มี

- การแจ้งเตือนจากตัวแอปเอง (เว็บแอปที่ไม่มีเซิร์ฟเวอร์ส่งแจ้งเตือนตอนปิดแอปอยู่ไม่ได้ ใช้ปฏิทินเตือนแทนตามด้านบน)
- การซิงก์ข้ามเครื่อง (ต้องมีระบบบัญชีและฐานข้อมูล)
